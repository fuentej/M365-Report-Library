# Candidate: mailbox exfiltration risk

Status: sources verified against Microsoft Learn; nothing built. Written for BRO-317 so the build issue
can be written without guessing. Nothing here was run against a tenant.

Cloud names follow the library: `Commercial`, `GCC`, `GCCHigh` (`-Environment`). Exchange Online in
GCC High connects with `-ExchangeEnvironmentName O365USGovGCCHigh`
([app-only auth](https://learn.microsoft.com/powershell/exchange/app-only-auth-powershell-v2)); Graph uses
`https://graph.microsoft.com` for Commercial and GCC and `Connect-MgGraph -Environment USGov` for GCC High
([national cloud deployments](https://learn.microsoft.com/graph/deployments)).

## How to read the table

* `Available` / `NotAvailable` appear only where a Microsoft page says so; the link is in the cell.
* `UNVERIFIED` means no Microsoft page found says either way. The collector should ask for the data and
  record a refusal in `run.log`, as the existing reports do.
* **Role** is the least privileged role a Microsoft page names. Where the cmdlet page only defers to
  [Find the permissions required to run any Exchange cmdlet](https://learn.microsoft.com/powershell/exchange/find-exchange-cmdlet-permissions),
  the cell says so and names the role whose description matches
  ([Permissions in Exchange Online](https://learn.microsoft.com/exchange/permissions-exo/permissions-exo#roles-in-exchange-online)).
  That match is an inference, not a Learn statement; confirm it in a test tenant before the build issue
  states it as fact.
* Exchange availability for GCC and GCC High comes from the
  [Exchange Online for US government environments](https://learn.microsoft.com/office365/servicedescriptions/office-365-platform-service-description/office-365-us-government/exchange-online-for-us-government-environments#exchange-online-features)
  service description, which lists features, not cmdlets. Where a row below rests on a feature row
  ("Inbox rules", "Mail flow rules", "Delegate access", "Remote Windows PowerShell access"), the cell
  names the row.

Consolidated notes:

* Source 1, 2, 3, 4: Learn describes these as Exchange Online cmdlets. For GCC and GCC High the only
  Microsoft statements found are the feature rows named in each cell; none names the cmdlet.
* Source 5: the Graph pages list the national cloud deployments. "US Government L4" is the GCC High
  endpoint; GCC calls the global endpoint, per the [deployments](https://learn.microsoft.com/graph/deployments) page.
* Source 6: `MailItemsAccessed` is an Audit (Standard) action for E3 and E5 users. Show the
  `SensitivityLabel` property as not collected when the user has no Audit (Premium) license.
  Do not show the access event itself as not collected for that reason. A `ReturnLargeSet` session
  that reaches 50,000 records is a failed window, not a complete export.
